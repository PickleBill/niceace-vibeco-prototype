Two-pronged plan

NiceAce plus Vibeco
01

Get NiceAce out

Ship sponsor-funded hole-in-one and par-3 challenge pilots with claim verification, event setup, recap pages, and compliance review before peer wagering.

02

Bring it back to Vibeco

Treat NiceAce as the proving ground for Vibeco's build-on-demand engine: accept requests, run agents, generate Lovable prompts, and commit Claude Code work through GitHub.

03

Mine the market

Scan public golf, tournament, and sponsor conversations for pain points, cluster them, and promote only high-signal themes into PRDs.
